หน้าแรก ฝึกภาษามือ

นโยบายความเป็นส่วนตัว

ฉบับ 2026-08-v1 · ปรับปรุงล่าสุด 30 สิงหาคม 2569

สรุปสั้นๆ — ภาพจากกล้องของคุณไม่เคยออกจากเครื่องคุณ เราไม่เก็บชื่อ อีเมล เบอร์โทร หรือสิ่งใดที่ใช้ระบุตัวคุณได้ สิ่งที่เก็บมีเพียงคำตอบแบบสอบถามที่คุณกดยินยอม กับสถิติการฝึกแบบไม่ระบุตัวตน

1. ภาพจากกล้อง

การตรวจจับท่ามือทั้งหมดทำงานด้วยไลบรารี MediaPipe Hands ที่รันอยู่ใน เบราว์เซอร์ของคุณเอง ภาพแต่ละเฟรมถูกแปลงเป็นพิกัดจุด 21 จุดบนมือ ใช้ตัดสินท่า แล้วถูกทิ้งทันทีในเฟรมถัดไป

  • ไม่มีการอัดหรือบันทึกวิดีโอ
  • ไม่มีการส่งภาพหรือพิกัดจุดใดๆ ขึ้นเซิร์ฟเวอร์
  • เมื่อคุณปิดกล้องหรือปิดแท็บ การเข้าถึงกล้องจะหยุดทันที

2. ข้อมูลที่เราเก็บจริง

ข้อมูลเก็บเมื่อไรเก็บไปทำไม
คำตอบแบบสอบถาม (บทบาท ช่วงอายุ ระดับความรู้ เป้าหมาย เหตุผล ช่องทางที่รู้จัก) เมื่อคุณติ๊กยินยอมและกดส่ง เข้าใจว่าใครใช้ระบบนี้ เพื่อปรับเนื้อหาให้ตรงกลุ่ม
ความคิดเห็นและคะแนนความพึงพอใจ เมื่อคุณกดส่งในหน้าความคิดเห็น ปรับปรุงความแม่นยำและการใช้งาน
สถิติการฝึกแบบไม่ระบุตัวตน (ท่าไหนผ่าน ท่าไหนไม่ผ่าน ใช้เวลานานแค่ไหน) เมื่อคุณออกจากหน้าฝึก หาว่าท่าไหนที่เกณฑ์ระบบเข้มหรือหลวมเกินไป
ขนาดหน้าจอและภาษาของเบราว์เซอร์ พร้อมแบบสอบถาม แก้ปัญหาการแสดงผลบนอุปกรณ์ต่างๆ
ค่าแฮชของหมายเลข IP ทุกครั้งที่ส่งข้อมูล จำกัดจำนวนครั้งการส่ง เพื่อกันบอทยิงข้อมูลขยะ

3. เรื่องหมายเลข IP

เราไม่เก็บหมายเลข IP ของคุณ สิ่งที่เก็บคือค่าที่ผ่านการแฮชแบบทางเดียว (SHA-256) ร่วมกับค่าสุ่มลับที่เก็บไว้ฝั่งเซิร์ฟเวอร์ ค่าที่ได้แปลงกลับเป็น IP เดิมไม่ได้ ใช้เพียงเพื่อดูว่า "คำขอนี้มาจากที่เดียวกับคำขอก่อนหน้าหรือไม่" ในช่วงเวลาสั้นๆ

4. สิ่งที่เราไม่เก็บ ไม่ว่ากรณีใด

  • ชื่อ นามสกุล ชื่อเล่น
  • อีเมล เบอร์โทรศัพท์ บัญชีโซเชียลมีเดีย
  • ภาพนิ่งหรือวิดีโอจากกล้อง
  • ตำแหน่งที่ตั้งของคุณ
  • คุกกี้ติดตามหรือเครื่องมือวิเคราะห์ของบุคคลที่สาม

เนื่องจากเราไม่เก็บสิ่งที่ระบุตัวคุณได้เลย จึงไม่มีวิธีเชื่อมโยงคำตอบชุดใด กลับมาหาตัวคุณ ทั้งโดยเราเองและโดยผู้อื่น

5. เก็บไว้ที่ไหน และนานแค่ไหน

ข้อมูลถูกเก็บในฐานข้อมูล PostgreSQL บนบริการ Supabase การเข้าถึงถูกปิดกั้นด้วย Row Level Security แบบปฏิเสธทุกอย่างเป็นค่าตั้งต้น เขียนได้เฉพาะผ่านโค้ดฝั่งเซิร์ฟเวอร์ของเราเท่านั้น และอ่านได้เฉพาะผู้ดูแลระบบที่ล็อกอินเข้าแผงควบคุมของ Supabase

กุญแจที่ใช้เขียนฐานข้อมูลถูกเก็บเป็นตัวแปรสภาพแวดล้อมบนเซิร์ฟเวอร์ ไม่เคยถูกส่งมายังเบราว์เซอร์ของคุณ

เราตั้งใจเก็บข้อมูลไว้ไม่เกิน 24 เดือน แล้วลบทิ้ง

6. สิทธิของคุณ

ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA) เจ้าของข้อมูลมีสิทธิขอเข้าถึง แก้ไข หรือลบข้อมูลส่วนบุคคลของตน

อย่างไรก็ตาม ข้อมูลที่ระบบนี้เก็บเป็นข้อมูลที่ไม่ระบุตัวตนตั้งแต่ต้น เราจึงไม่มีทางค้นหาว่าแถวไหนในฐานข้อมูลเป็นของคุณ หากคุณต้องการให้ลบสิ่งที่ส่งมา กรุณาแจ้งเวลาโดยประมาณและเนื้อหาที่พิมพ์ไว้ เพื่อให้เราค้นหาและลบให้ได้

7. บริการภายนอกที่ระบบเรียกใช้

  • jsDelivr — ส่งไฟล์ไลบรารี MediaPipe มาให้เบราว์เซอร์คุณ
  • Google Fonts — ส่งฟอนต์ภาษาไทย
  • Vercel — ให้บริการเว็บและรันโค้ดฝั่งเซิร์ฟเวอร์
  • Supabase — ฐานข้อมูลที่เก็บคำตอบแบบสอบถาม

บริการเหล่านี้อาจเห็นหมายเลข IP ของคุณตามธรรมชาติของการเชื่อมต่ออินเทอร์เน็ต ซึ่งอยู่นอกเหนือการควบคุมของเรา

8. การเปลี่ยนแปลงนโยบาย

หากมีการแก้ไขสาระสำคัญ เราจะเปลี่ยนหมายเลขฉบับด้านบน คำยินยอมที่คุณให้ไว้จะถูกบันทึกพร้อมหมายเลขฉบับที่คุณเห็นในตอนนั้นเสมอ
